# UWB Studio 界面效果图

本目录为设计预览，不是已运行的 Electron 应用；图中数值为示意数据。
每张图左侧为浅色主题，右侧为深色主题。

- 01-clear-workbench.png：清透工作台。蓝色重点、侧栏串口列表、矩阵加各节点观测卡片。
- 02-soft-layers.png：柔和浮层。米白/深森林色、柔和圆角、顶部多串口连接卡片、右侧选中节点观测详情。
- 03-precision-console.png：精密仪表台。石墨/琥珀色、等宽测量数字、紧凑的工程仪表布局。

## 后续实现的共同约束

- Electron 项目仅放在父级 electron 文件夹；广播参考固件目录不变。
- 同时打开多个真实串口；逐端口连接、断开、配置波特率，并识别各串口上报的本机 RAC。
- 使用现有 @SRV2 / @SRV2_STATUS 数据，矩阵每行来自该节点自己的实际计算；两个方向各自更新，不镜像、不平均、不填补缺失距离。
- 对角线0，未知或过期为“—”；每个节点可单独查看观测、类型、年龄和历史。
- 原始数据与CSV导出；串口处理与界面渲染隔离，有界缓存，曲线按显示节奏批量更新。
- 浅色/深色/跟随系统。状态不只用颜色表达，保证数字和文字对比度。
- 静态效果图不代表已实现动画。建议主题切换约220ms、节点切换约180ms、测量更新短暂淡入；只对透明度和位移做过渡，数字保持真实采样值。
- 历史曲线遇到数据缺口断开，不通过补点制造连续测量。支持减少动态效果，避免每条高频串口数据触发整页动画。

选定视觉方案后再建立 Electron 工程、接入串口并验证实际交互及动画流畅度。
