# UWB Studio

面向 ESP32-C6 和 STM32 UWB 节点的桌面工作台，用于多串口测距观测、节点位置显示、协同定位及实验录制回放。

## 功能

- **独立距离矩阵**：每个串口分别显示该观察节点收到的距离，包含其能够重建的第三方节点对。不同观察串口的距离不会混合覆盖。
- **最新位置**：矩阵对角线显示节点上报的原始 X、Y 坐标；Z 轴可在设置中开启。合法的 `(0, 0, 0)` 是有效位置，未收到、过期和来源断开分别显示状态。
- **协同定位**：通过静止采集建立距离拓扑，使用各节点局部位移完成移动初始化，再联合有效测距执行 UKF 修正。
- **实验录制**：保存原始接收字节、距离观测及实验阶段操作，供离线复核和定位回放。
- **文件回放**：直接从记录文件重放定位，无需连接串口；带有操作记录的实验可自动恢复阶段切换。
- **串口回放**：将记录中的原始字节发送到指定串口，独立于软件内的文件定位回放。
- **节点与终端**：按设备声明的能力提供广播测距、纯监听、节点配置、快捷命令和终端筛选；支持浅色、深色及系统主题。

## 安装与运行

Windows 用户可从 [Releases](https://github.com/Joey0609/uwb-studio/releases) 下载安装包或便携程序。

从源码运行需要 Node.js 和 npm：

```powershell
npm ci
npm start
```

构建 Windows 安装包和便携程序：

```powershell
npm run dist -- --publish never
npm run verify:release
```

产物位于 `release/`，不纳入源码仓库。

## 连接设备

1. 连接 UWB 板的数据串口，点击“一键连接”或手动添加串口。
2. 默认波特率为 `115200`，文字编码可选自动、UTF-8 或 GBK。
3. 等待节点地址和能力识别，再按需启动广播测距或纯监听。连接串口本身不会自动启动测距。
4. 在总览查看各串口独立矩阵，在节点页或终端查看所选观察串口的数据。

双主控板的 STM32 串口与同板 ESP32-C6 串口是不同入口。应连接输出 UWB 协议的数据口，不能仅凭 USB 芯片类型判断串口职责。惯导发送板也有独立协议。

“USB 已连接节点”逐口执行控制；“无线全网”通过网关广播控制。软件只根据收到的设备确认显示执行结果，不以命令写入成功代替设备执行成功。纯监听与被动定位功能仅在固件声明支持时启用。

## 距离与位置

距离使用电脑接收时间判断显示有效期，连续约三秒没有新的有效观测后显示未知。固件发送的无效距离仍保存在原始记录中，不延长原有距离的显示期限。

位置缓存独立于定位实验，连接并收到合法位置消息后即可显示。多个串口上报同一节点时，采用电脑最近收到的合法记录，同时保留来源；同一来源的重复、倒序位置不会刷新有效期。超过约一秒未更新时保留最后坐标并标记过期。暂停矩阵只冻结显示，后台采集继续。

对角线是节点上报的原始位置；协同定位图中的修正结果在电脑端计算，不回写为设备惯导坐标。

## 协同定位

选择一个观察串口作为实验来源，按以下阶段进行：

1. **静止采集**：累计有效距离均值，形成完整距离拓扑及初始相对布局。
2. **初始位置**：进入该阶段时，把每个节点当前收到的惯导坐标设为局部位移原点。过期或缺失位置不能作为原点；静止采集期间的惯导位移不带入初始化。
3. **位置修正**：移动初始化满足可观测条件后，由用户进入该阶段；软件按一秒窗口联合有效测距和节点位移执行 UKF。

只有一个节点移动、其余节点保持静止也是支持的场景。是否可以初始化取决于距离拓扑、有效位置及移动观测，不能只看某一条测距是否成功。

定位仍要求位置历史覆盖对应测距时刻。缺少位置时不补造坐标，没有有效测距的窗口不执行 UKF。节点重启或可识别的位置来源代次改变后，需要重新建立实验，避免混合不同坐标零点。

详细算法与协议条件见 [协同定位](docs/LOCALIZATION.md)。

## 记录与回放

普通采集默认保存在用户文档目录的 `UWB Studio/recordings/`。实验保存目录可在设置中选择，默认使用用户文档目录的 `UWB Studio/experiments/`。

| 文件 | 内容 |
| --- | --- |
| `.raw` | 串口收到的原始混合字节 |
| `observations.csv` | 通过校验的距离观测 |
| `ComRecvData_*.csv`、`Experiment-*.csv` | 按接收块保存的 `ts,len,hexStr` 数据 |
| `.session.json` | 与实验 CSV 配套的用户操作及阶段记录 |

实验 CSV 和同名操作记录应放在同一目录。文件回放支持暂停、继续和倍速；播放速度不改变算法使用的记录时间。没有操作记录的旧文件可手动推进阶段，但不能凭空还原当时的操作。

结束实验时使用“重置”保存本轮记录。磁盘错误、记录不完整和保存失败会显示状态；保存失败时保留当前记录供重试。详细说明见 [录制与回放](docs/REPLAY.md)。

## 工程结构

```text
main/       Electron 主进程、串口采集、协议模型、定位和记录
renderer/   页面、矩阵、图表及交互
assets/     应用图标
docs/       协同定位、回放、快捷命令和验证记录
tools/      发布产物校验工具
versions/   发布说明
.github/    GitHub 构建发布工作流
```

串口采集与文件写入运行在独立进程，渲染器没有 Node.js 权限。源码仓库不包含依赖目录、安装包、采集记录、构建缓存或测试目录。
