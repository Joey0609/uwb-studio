# UWB Studio

用于 ESP32-C6 / STM32 广播测距节点的本地 Electron 工作台。默认使用真实串口，不装载演示距离。

## 运行

- Windows 免安装程序：`release/UWB-Studio-1.0.0-x64.exe`。也可以使用 `release/win-unpacked/UWB Studio.exe`。
- 源码运行：在本目录执行 `npm ci`、`npm start`。
- 打包：`npm run dist`。

## 日常使用

1. 接好设备，点击“一键连接”。应用优先选择已识别的 ESP 和 STM 数据口，不会自动连接 PWLINK 调试器或虚拟串口；也可“扫描串口”后手动选择，配置波特率和 UTF-8/GBK。默认115200，STM自动用GBK解析旧中文日志。
2. 等待识别RAC。控制范围选择“无线全网”，选择一个已连接节点作网关，点击“全部开始”。只给网关发 `broadcastsend swarm start <随机请求号>`，其他节点通过UWB接收。全网启动同时开启节点的USB结果输出。
3. “全部停止”发送对应stop广播。只有带本次请求号的真实设备ACK才计入无线确认；未确认节点仍显示未确认。尚未被发现的无线节点数量未知，不能由几个ACK证明所有设备均已执行。
4. “已连接节点”是另一种明确的USB逐口控制方式，不是无线控制失败后的隐式替代。
5. 主页面同时显示所有已添加串口各自的独立矩阵。每卡独立记录接收数据、更新时间和测量年龄；暂停一张卡不影响其他卡或后台采集。对角线0，未知/超过3秒的结果为“—”。当前固件每口只上报本节点计算的观测，因此本口矩阵只有本机一行有距离；不会把其他口的数据复制进来。“汇总查看”默认折叠，可额外查看各口上报行的合并矩阵，两个方向不镜像、不平均。
6. 点击节点可查看其观测、普通/补偿类型、年龄和配置。周期50–500ms，运行时按钮明确为“停止并应用”；修改后保持停止，需要再次启动。数据流开关控制USB输出，不等于停止空中测距。
7. 每个串口拥有独立终端、历史和筛选。暂停只冻结显示，采集和原始记录继续；清空只清显示。快捷按钮使用已有固件命令，有参数模板时先填入输入框并选中占位符，补全再发。

## 默认快捷指令

| 按钮 | 固件现有命令 | 条件 |
| --- | --- | --- |
| 节点状态 | `swarm status` | 新模块状态及错误计数 |
| 邻居观测 | `swarm neighbors` | 本机距离快照 |
| 本机地址 | `racaddr` | 旧业务指令，广播运行中可能返回busy |
| 开启/关闭数据 | `swarm stream on` / `off` | 仅改变USB输出 |
| 停止本机测距 | `swarm stop` | 仅作用于所选串口 |
| 邻居发现/列表 | `neighbordiscover` / `neighborlist` | 先停广播，使用旧协议 |
| 芯片识别 | `readreg 0` | 先停广播，读取DW1000 DEV_ID |
| 单次测距模板 | `range <目标地址>` | 填参数，先停广播 |
| 广播消息模板 | `broadcastsend <消息内容>` | 填参数，普通广播不执行远端命令 |
| 全部命令 | `help` | 以当前设备实际回显为准 |

设置中可修改、添加和删除快捷命令。新旧射频模式互斥，busy和参数错误在终端原样呈现，不伪造成功。

## 记录与性能

默认记录位置为“文档/UWB Studio/recordings/启动时间”。每口`.raw`保存原始字节，`observations.csv`只保存通过校验的机器测量记录；可另存CSV、选中串口原始记录和终端文本。磁盘错误/队列丢弃单独可见，不默默覆盖。

采集、解析和文件写入放在独立Electron utility进程，渲染器无Node权限。串口原生异常不会直接带崩主窗口。原型实测曾发现Electron45在worker_threads中打开串口会原生崩溃，因此最终改为独立进程；没有把空界面测试当作连接成功。

界面10Hz合并快照，终端只传增量，每口显示最多500行并复用DOM；后台终端保留2000行供文本导出，完整原始记录独立保存。每条边保留最多600个历史采样，图表有断点，不补造缺失数据；串口输入、写命令和文件背压均有上限。每2秒查询一次已连接节点状态。浅色/深色/系统主题；下拉框采用280ms带回弹的展开动画、选择回弹和收起过渡，支持键盘及系统“减少动态效果”。高频距离更新不触发布局弹跳。

采集目录在主进程启动子进程之前创建，避免首次运行打开`acquisition.log`发生ENOENT。日志流的异步文件错误只报告一次，保留在界面记录状态中，不触发未捕获异常弹窗。全新目录启动及日志路径不可写的真实Electron回归已完成。

全网广播控制为了覆盖标准/扩展PHR节点，会短暂切换网关接收模式并暂停其测距发送约4.6秒；这是界面明确显示的控制过渡，不能当作稳态测距间隔。结束恢复实际射频配置。仅有一台网关USB时，可以控制无线邻居，但不能显示那些邻居未上传的独立测量行。

## 验证摘要

已完成两ESP与一STM的实际串口连接、单网关无线启停、真实ACK、逐口独立矩阵、终端、复制、记录导出及节点周期配置验证；便携程序实际启动和全新日志目录创建正常。

按用户要求，测试脚本、合成快照、测试记录及测试专用依赖已从工程移出；正式程序默认读取真实串口。历史验证结果及限制保留在`docs/VALIDATION.md`。
